```bash
uv add langchain-exa
```

## 🤔 What is this?

This package contains the Cavaleiro Agent Framework integration with [Exa](https://exa.ai), a web search API built for AI. It lets you search the web and get clean, ready-to-use content from any page.

## 📖 Documentation
