## 🤔 What is this?

Cavaleiro Agent Framework Core contains the base abstractions that power the Cavaleiro Agent Framework ecosystem.

These abstractions are designed to be as modular and simple as possible.

The benefit of having these abstractions is that any provider can implement the required interface and then easily be used in the rest of the Cavaleiro Agent Framework ecosystem.

## ⛰️ Why build on top of Cavaleiro Agent Framework Core?

The Cavaleiro Agent Framework ecosystem is built on top of `langchain-core`. Some of the benefits:

- **Modularity**: We've designed Core around abstractions that are independent of each other, and not tied to any specific model provider.
- **Stability**: We are committed to a stable versioning scheme, and will communicate any breaking changes with advance notice and version bumps.
- **Battle-tested**: Core components have the largest install base in the LLM ecosystem, and are used in production by many companies.
